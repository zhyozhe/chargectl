# chargectl — Chromebook 充電キープ・ミニアプリ

常時給電で使う Chromebook のバッテリーを、選んだ残量で保持しつづけるための小さな常駐プログラムです。あわせて充電速度（充電電流の上限）と、見回りの周期も画面から選べます。

操作はすべて端末自身のブラウザで開く画面（`http://127.0.0.1:8765/`）から行います。画面を閉じても常駐側が保持をつづけます。外部にポートは開きません（127.0.0.1 のみ）。

## できること

画面は3段のボタンだけです。いま有効な値には印が付きます。

- **保持する残量**: 50 / 55 / 60 / 70 / 80 / 100（100 は保持オフ＝満充電）
- **充電速度の上限**: 500 / 1000 / 2000 / 3000 mA / 無制限
- **見回りの周期**: 30秒 / 1分 / 5分 / 10分

選んだ値は端末内に保存され、再起動しても維持されます。

状態表示の欄には、電池の % に加えて電圧（V）・電流（mA）・電力（W）・残量（mAh）・電池の状態（充電中／放電中など）も出ます。電力は電圧×電流で計算した値です。電流は充電中は＋、放電中は−で表示し、電流と状態の文字は充電中は緑、放電中はオレンジに色分けします。充電器側の入力電圧（EC が報告する実測値で、USB PD の契約電圧の額面ではありません）も表示します。

## 仕組み

Chromebook の EC（組み込みコントローラ）には、もともと2つの仕掛けがあります。

- Battery Sustainer: 指定した残量の帯で充電を止める（`ectool chargecontrol`）
- 充電電流の上限: 電池へ流す電流の上限を mA で指定する（`ectool chargecurrentlimit`）

chargectl はこの2つへ値を書き、以後は「見回り役（keeper）」として周期的に状態を読み直し、ずれていたら直します。見回りが必要なのは、OS 側の powerd が起動時とポリシー通知（ログイン、ロック解除、電源まわりの設定変更など）のたびに、純正の設定（充電制限が有効なら 80%、速度は無制限）を書きに来るためです。powerd は EC の実値を読まないので、外から変えられたことに気づきません。つまり書き合いは起きず、後から見回りが直せば済みます。

充電速度だけは、EC 側に現在の上限を読み戻す手段がありません。そのため keeper は読み戻し照合ではなく、見回りのたびに保存値をそのまま書き直します（同じ値を書くのは無害です）。

保険として、純正の充電制限（設定画面の「バッテリーを保護する」相当、80%）は有効なまま残す運用を推奨します。chargectl が何らかの理由で止まっても、80% 保持に落ちるので、満充電のまま放置されることはありません。

## 前提

- 開発者モードの Chromebook で、root シェルが使えること
- `/etc/init` へファイルを置けること（環境によっては rootfs の検証解除が要ります）
- EC が Battery Sustainer と充電電流制限に対応していること。目安として、root シェルで次を打って `Battery sustainer` の行が出れば対応しています

```
ectool chargecontrol
```

- バイナリのビルドには gcc のある環境が要ります（静的リンクで作るので、ビルドは別の Linux 機でも構いません）

## 導入

```
# ビルド（gcc のある環境で）
gcc -static -O2 -o chargectl chargectl.c

# 端末側（root シェルで、バイナリと conf を端末へ運んでから）
sh install.sh
```

`install.sh` はバイナリを `/usr/local/bin/chargectl` へ、ジョブ定義を `/etc/init/chargectl.conf` へ置いて、ジョブを起動します。あとは端末の Chrome で `http://127.0.0.1:8765/` を開いてください。ランチャーに置きたい場合は、Chrome のメニューからショートカットを作成すると便利です。

設定ファイルは `/usr/local/share/chargectl/` に置かれます（`target` / `speed` / `interval`）。ログは `/var/log/chargectl.log` です。

## 注意

- ChromeOS の OS 更新で `/etc/init` 側（rootfs）が入れ替わると、ジョブ定義が消えて起動しなくなることがあります。その場合は `chargectl.conf` を置き直してください。`/usr/local` 側（バイナリと設定）は残ります。
- 保持を 100（オフ）に選んだ場合、上記の「80% への保険」は働きません。保持オフは利用者の明示的な選択として扱います。
- 充電速度の上限は充電側だけに効きます。本体の消費や放電には影響しません。

## 動作確認環境

- 機種: pujjoteen（board: nissa）、ChromeOS 16836.32.0
- 保持・速度・周期の全段と、再起動をまたいだ維持（起動直後の EC 初期状態からの復帰、powerd が書いた 80% の書き戻し、保存した速度上限の起動時適用）まで実機で確認済みです。
